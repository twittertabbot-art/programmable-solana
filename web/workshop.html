What a listing means

Reviewed and approved

Programmable reviews a hook's code against ten rules before it can open a pool. An approved hook carries the mark Reviewed by Programmable, with the date and a link to its report.

The code is frozen

A pool takes a hook only when nobody can change its code. An approval covers that one frozen program. The accounts a hook keeps can still change, as far as its code allows.

Two voices

The chain says what a hook may do. Its author says what it does, in a file the author hosts. This site shows that file next to the chain's facts.

A review is not an audit and not a promise. A hook can refuse a trade it is called on. Read a hook's report and its page before you buy a coin on it or launch one. How the review works
